# Resume Studio

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

A no-backend resume builder made with plain HTML, CSS, and JavaScript.

> Copyright (c) 2026 [remilsalim](https://github.com/remilsalim) — Licensed under the [MIT License](./LICENSE).

## Files
- `index.html` — form and live preview
- `style.css` — editor and resume design
- `print.css` — A4 print/PDF styles
- `script.js` — dynamic sections and preview rendering

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Fill in the form. Use the `+ Add` buttons for multiple entries.
4. Click **Export to PDF**.
5. In the print dialog, choose **Save as PDF**, paper size **A4**, and turn off browser headers/footers if shown.

No server, framework, or backend is required.

## Notes
- This project does not transmit or persist resume details.
- Keep the resume concise. A long resume may spill onto a second page; shorten content if a strict one-page PDF is needed.
- The font import uses Google Fonts when online; system fallbacks are included.
